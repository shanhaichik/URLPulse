## Первый запуск

Для запуска Пульса URL из исходного кода установите Node.js 24.x и запустите приложение из терминала.

```bash
git clone https://github.com/shanhaichik/URLPulse.git
cd URLPulse
npm ci
npm run build
npm start
```

Откройте полную ссылку из терминала. Сервер слушает `127.0.0.1:8731`, а ключ из ссылки создаёт сессию в браузере и исчезает из адресной строки. При перезапуске откройте актуальную ссылку. Не передавайте ключ другим людям. Для постоянного ключа задайте `PULSE_WEB_ACCESS_KEY` в `.env` и используйте случайное значение из 32–128 символов base64url. Чтобы остановить сервер, нажмите `Ctrl+C`.

Чтобы запустить Electron из той же папки, после `npm ci` выполните `npm run desktop`. Закрытие окна оставляет приложение в фоне. Выберите **Открыть Пульс URL** или **Выход** через значок в строке меню либо области уведомлений. Перед заменой или удалением установленного приложения выберите **Выход**. Команды сборки локальных установщиков без подписи приведены в [документации разработчика](../development/README.ru.md#сборка-установщиков).

Если вы собрали установщик, откройте DMG на macOS и перетащите **Pulse URL** в «Программы». На Windows x64 запустите полученный файл `Pulse-URL-<version>-win-x64-Setup.exe`, затем откройте **Pulse URL** из меню «Пуск».

### Первая проверка

1. Нажмите **Новый проект**, введите название и нажмите **Создать проект**.
2. Нажмите **Добавить URL → Список URL**. Вставьте `https://example.com/` и `https://example.org/` по одному адресу в строке. Нажмите **Добавить адреса**, проверьте итог добавления и нажмите **Готово**.
3. Нажмите **Проверить проект**. Откройте **Журнал запусков** и выберите отчёт. В нём видны итог проверки, HTTP-код и время ответа для каждого адреса, по которому получен результат. Для следующей проверки можно выбрать отдельный URL или часть списка.

## Язык интерфейса, писем и выгрузок

При первом запуске интерфейс русский. Выберите **Русский** или **English** в верхней панели или в открытом диалоге. В Electron язык также доступен в меню приложения и через значок в строке меню либо в трее. Подписи обновляются сразу. Проект, текущий экран, выделенные URL и черновики сохраняются.

В веб-версии выбор хранится в профиле браузера и синхронизируется между открытыми вкладками того же адреса. В Electron он хранится в локальных настройках приложения. Подписи стандартных элементов операционной системы следуют языку ОС.

**CSV для Excel** использует язык интерфейса в момент запуска выгрузки. Форматы отчётов CSV и JSON сохраняют прежние поля, а даты записываются в ISO 8601. Язык фоновых писем задаётся отдельно для всех проектов установки. [Настройка писем](#расписание-и-уведомления)

## Адреса, проверки и рабочие группы

Вкладка **Адреса** показывает рабочий список проекта. Можно вставить до 1 000 URL за раз, искать адреса, фильтровать по статусу и сортировать по заголовкам таблицы. **Сбросить фильтры** возвращает исходную выдачу. Кнопка запуска в строке проверяет один URL. Чтобы проверить несколько, отметьте строки и нажмите **Проверить выбранные**. **Проверить проект** использует весь активный список.

Нажмите URL, чтобы открыть историю проверок и увидеть статус текущей версии. При изменении URL создаётся новая версия, а предыдущие результаты остаются в истории. Кнопка **Открыть в браузере** открывает сохранённый адрес в обычном браузере.

**Остановить проверку** доступна в панели прогресса, очереди и отчёте активного прогона. Отчёт со статусом **Остановлена** сохраняет уже полученные результаты. Если доступен повторный запуск, он проверит весь исходный список с актуальными настройками HTTP-профилей.

В **Настройки → Проверки** задайте число одновременных запросов от 1 до 24, по умолчанию 6. Нажмите **Сохранить настройки**. Лимит применяется при начале следующего запуска, в том числе для задания, которое уже стоит в очереди.

### Группы

Чтобы отдельно проверить набор адресов, например страницы, которые вы проверяете после выкладки, нажмите **Новая группа** в разделе **Адреса**. Отметьте строки общего списка и нажмите **Добавить в группу**. Один URL может состоять в нескольких группах.

Выберите группу в списке. **Проверить группу целиком** ставит в очередь все её активные URL, включая скрытые фильтром. Состав прогона сохраняется при постановке в очередь. **Убрать из группы** исключает выбранные адреса из этой группы. Нажмите **Прогоны группы**, чтобы открыть отдельный отчёт. **Экспорт группы** выгружает результаты её запусков и их перезапусков.

## Отчёты и сравнение

Проверка отправляет GET с общим тайм-аутом 10 секунд и максимум пятью перенаправлениями. Итоговый ответ HTTP 2xx считается доступным. Подробности результата включают время до получения заголовков, конечный URL, число перенаправлений, `Content-Type`, `Content-Length` и диагностику сбоя.

В отчёте можно искать по URL или названию и выбрать фильтры **Статус** и **HTTP-код**. Чтобы применить их, нажмите **Найти**. При наличии истории фильтр **Изменение** помогает найти новые сбои, восстановления и смену кода или конечного URL. Отчёт определяет изменение по предыдущему по времени результату той же версии адреса из завершённого запуска.

### Сравнение двух прогонов

1. Откройте **Журнал запусков → Сравнить прогоны** и выберите **Было** и **Стало**. Из отчёта можно нажать **Сравнить с другим прогоном**. Открытый прогон будет справа, предыдущий завершённый появится слева, если он есть. Для сравнения подходят завершённые и остановленные прогоны с результатами.
2. Нажмите **Новые сбои** или другой счётчик, чтобы отобрать строки. Счётчики показывают всю пару, и один URL может попасть в несколько категорий. Раскройте строку, чтобы посмотреть HTTP-коды, время ответа и диагностику обеих проверок. Замедление отмечается, когда успешная проверка той же версии URL стала дольше как минимум на 200 мс и 30%.
3. Используйте **Экспорт по фильтрам**, чтобы выгрузить всю текущую выборку сравнения с данными обеих сторон. Доступны CSV, **CSV для Excel** и JSON.

Кнопка скачивания в строке журнала выгружает один прогон. Экспорт из открытого отчёта учитывает применённые фильтры и включает результаты со всех страниц. **CSV для Excel** использует заголовки на выбранном языке, кодировку UTF-8 с BOM и точку с запятой в роли разделителя. При открытии такого файла через мастер импорта Excel можно явно указать эту кодировку и разделитель.

## Импорт sitemap

**Добавить URL → Файл sitemap** или **Ссылка на sitemap** подходит для быстрого импорта в **Адреса**. Поддерживаются XML, GZIP и вложенные индексы. Ограничения одного импорта составляют 8 МиБ на распакованный документ, 32 МиБ суммарно, 100 документов и 50 000 записей. Если вложенный sitemap недоступен или не разбирается, быстрый импорт прекращается до добавления адресов.

### Каталог больших sitemap

1. Вставьте ссылку и нажмите **Импортировать** или выберите XML/XML.GZ через **Загрузить файл**. Каталог поддерживает до 1 000 документов, 256 МиБ на документ, 2 ГиБ распакованных данных за импорт и 1 000 000 уникальных URL на проект. Пока сервер или Electron запущен, импорт работает в фоне. Его можно приостановить, возобновить или отменить.
2. Для следующей версии источника нажмите **Обновить** или **Загрузить новую версию**. Каталог хранит текущую и предыдущую опубликованные версии источника. Используйте **Изменения**, чтобы найти новые, исчезнувшие или изменившиеся по `lastmod` URL. Введите **Домен** или **Начало пути** и нажмите **Найти**, чтобы применить текстовые фильтры.
3. Отметьте URL или укажите число первых адресов в поле **Первые URL по фильтру**, до 5 000 за операцию. **Проверить** создаёт разовый прогон в журнале. **В рабочий список** переносит адреса в **Адреса**, чтобы включить их в последующие проверки проекта. **CSV по фильтру** выгружает всю применённую выборку, **CSV выбранных** выгружает отмеченные URL.

**Добавить все в «Адреса»** переносит уникальные URL из текущих опубликованных версий всех источников проекта. Выбранный источник и фильтры на этот перенос не влияют. **Остановить перенос** сохраняет уже добавленные адреса. Если приложение перезапустилось во время переноса, он продолжается с последней сохранённой позиции. Чтобы посмотреть статусы заданий, нажмите **История импортов**.

## Расписание и уведомления

В **Настройки → Расписание** отметьте **Включить расписание**, выберите дни недели, время и часовой пояс. Часовой пояс по умолчанию `Europe/Moscow`. Нажмите **Сохранить настройки** и проверьте время в строке **Следующий запуск**. Расписание берёт URL из активного рабочего списка. Пропущенные за время простоя запуски объединяются в один при возобновлении работы.

Закрыть вкладку можно, пока локальный сервер работает. В Electron раздел **Настройки приложения → Фоновая работа** позволяет управлять переключателем **Выполнять расписания**, а также настроить запуск при входе в систему, если он доступен. Нажмите **Сохранить фоновую работу**. При глобальной паузе начавшаяся проверка завершается, ручные запуски доступны, ожидающие плановые задания остаются в очереди.

В **Настройки → Уведомления** выберите **Все результаты**, **Только при ошибках** или **Выключено** и сохраните настройки. Лента открывается кнопкой **Уведомления** в шапке приложения. При открытии отчёта его уведомление отмечается прочитанным. Для очистки ленты используйте **Очистить уведомления**. История прогонов и доставка писем сохраняются.

Чтобы получать письма, укажите **Email получателя** в настройках проекта и подключите SMTP для своего способа запуска.

- В Electron заполните **Настройки приложения → SMTP** и нажмите **Сохранить SMTP**. В этом же разделе выберите **Язык писем** и отдельно нажмите **Сохранить язык писем**.
- Для локальной веб-версии сделайте копию `.env.example` с именем `.env`. Задайте `SMTP_HOST`, `SMTP_PORT`, `SMTP_TLS_MODE`, `SMTP_FROM` и, если SMTP-сервер требует входа, `SMTP_USER` и `SMTP_PASSWORD`. Часто используется `starttls` на порту 587 или `tls` на порту 465. Для писем на английском задайте `PULSE_EMAIL_LOCALE=en-US`. После изменений перезапустите сервер.

По умолчанию письма отправляются на русском. Выбранный язык применяется ко всем проектам этой установки.

При временной ошибке приложение повторяет отправку через 1, 2 и 4 минуты. Состояние и число попыток видны в ленте. Если работа прервалась во время отправки, появится статус **Доставка не подтверждена**. Проверьте почтовый ящик получателя. Автоматических повторов для этого статуса нет. Ссылка из письма открывает отчёт на компьютере с работающим Пульсом URL. В браузере нужна действующая локальная сессия.

## HTTPS, авторизация и прокси

### Российский корневой CA

Для HTTPS-проверок и удалённых sitemap доступны **Штатные сертификаты** и **Штатные сертификаты + Российский CA**. Для второго профиля требуется отдельный файл корневого CA Минцифры. Этот профиль расширяет доверие для выбранного проекта внутри приложения.

1. Скачайте **Russian Trusted Root CA** в PEM или DER и сохраните как `Russian_Trusted_Root_CA.cer`. [Госуслуги](https://www.gosuslugi.ru/crt)
2. Поместите файл в `cert/` в папке исходников для веб-версии или в папку `cert/` внутри каталога данных Electron, указанного ниже. При необходимости задайте абсолютный путь через `PULSE_RUSSIAN_CA_FILE` в `.env` для веб-версии или в окружении запуска Electron.
3. Полностью перезапустите приложение. В Electron сначала выберите **Выход**. Затем откройте **Настройки → HTTPS**, выберите **Штатные сертификаты + Российский CA** и нажмите **Сохранить настройки**.

Приложение проверяет SHA-256, назначение, самоподпись и срок действия сертификата. В отчёте и выгрузках `ERR_TLS_PROFILE_CA` указывает на проблему с файлом CA. Сверьте имя, расположение и файл с официальным источником.

### HTTP-профили

1. В **Настройки → HTTP-запросы** добавьте профиль с названием и адресом сервера, например `https://api.example.org:8443`. Профиль сопоставляется по схеме, хосту и порту и применяется ко всем путям этого сервера.
2. Задайте заголовки, если нужны, и выберите Basic, Bearer или API-ключ в отдельном заголовке. Для заголовка с токеном отметьте **Секрет**. Авторизация сайта и секретные заголовки требуют HTTPS.
3. При необходимости укажите HTTP- или HTTPS-прокси для проверки HTTPS-адресов через CONNECT. Для Basic-авторизации прокси используйте HTTPS-адрес прокси и отдельные поля логина и пароля.
4. Назначьте профиль по умолчанию для этого сервера или выберите его в настройках отдельного URL. Нажмите **Сохранить профиль**, затем **Проверить профиль**. Режим URL **Без профиля** использует прямое подключение.

На другом сервере после перенаправления используются стандартные заголовки. Прокси, явно заданный в профиле, продолжает действовать. В отчёте и выгрузках видны профиль, маршрут и этап сбоя. Ответ прокси `407` отображается отдельно от HTTP-кода сайта.

В Electron секреты шифруются средствами ОС. Пустое поле сохраняет прежнее значение. При смене сервера, имени секретного заголовка или логина введите секрет заново. Чтобы удалить секрет, удалите секретный заголовок или отключите соответствующую авторизацию. В локальной веб-версии определите в `.env` переменную, например `PULSE_REQUEST_SECRET_API_TOKEN`, перезапустите сервер и введите в поле секрета имя переменной. Чтобы заменить или удалить её значение, измените `.env` и перезапустите сервер.

### PAC-файл проекта

В **Настройки → HTTP-запросы** нажмите **Загрузить PAC-файл**, выберите локальный файл `.pac` в UTF-8 размером до 256 КиБ и сохраните. Кнопка **Проверить маршрут** показывает источник и порядок маршрутов для выбранного URL. Один проект использует один активный PAC-файл. Его можно заменить или отключить.

Для HTTPS поддерживаются `DIRECT` и прокси `PROXY` и `HTTPS`. Для HTTP доступен прямой маршрут. При сбое соединения приложение может попробовать следующий маршрут из PAC. Ошибка TLS или ответ прокси `407` останавливают запрос. `dnsResolve()` выполняет IPv4 DNS-запросы, поэтому правила, зависящие от файла `hosts` или настроек DNS браузера, могут выбрать другой маршрут.

В **Добавить доверенный прокси** введите схему, имя и порт, совпадающие с маршрутом PAC. Например, директиве `PROXY proxy.example.com:8080` соответствует `http://proxy.example.com:8080`. Запись действует только в текущем проекте.

- **Разрешить приватный IP прокси** допускает корпоративные адреса RFC 1918 и IPv6 ULA для выбранного прокси. Loopback и link-local блокируются. Приложение проверяет адрес назначения на каждом переходе.
- **Передавать имя цели в CONNECT** поручает прокси выбрать конечный IP. Включайте режим для прокси, чьи правила ограничивают соединения публичными целями.
- **Авторизация Basic** доступна для адреса с `https://` и доверенным сертификатом прокси. В Electron укажите пароль. В веб-режиме задайте пароль переменной `PULSE_REQUEST_SECRET_…` при запуске сервера и укажите её имя в форме. Запасной прокси использует собственные настройки. После переноса резервной копии на другой компьютер задайте секреты для этого профиля установки.

PAC применяется при проверках URL, импорте sitemap в **Адреса** и сетевых загрузках **Каталога**. Для проверок приоритет имеет прокси HTTP-профиля, а **Без профиля** задаёт прямой маршрут. Приложение заново выбирает маршрут для вложенного sitemap и перенаправления. Прогон и задача каталога фиксируют PAC и список доверенных прокси при постановке в очередь, быстрый импорт — при старте. Замена файла сохраняет доверенные прокси для новых задач, отключение очищает список проекта.

## Данные и резервное копирование

| Режим | Путь к базе по умолчанию |
| --- | --- |
| Локальная веб-версия | `data/pulse.sqlite3` в папке исходников |
| Electron на macOS | `~/Library/Application Support/Pulse URL/pulse.sqlite3` |
| Electron на Windows | `%APPDATA%\Pulse URL\pulse.sqlite3` |

Веб-версия и Electron создают разные базы. Свой путь для веб-версии задайте через `URL_PULSE_DB` в `.env`. Для Electron переменная `PULSE_DESKTOP_DATA_DIR` задаёт каталог профиля, включая базу, `cert/` и настройки. Используйте отдельную папку текущего пользователя с правами `0700` на macOS или Linux либо приватными ACL на Windows. Одну базу может открыть только один экземпляр. Служебный файл `*.owner-lock` оставляйте рядом с рабочей базой.

SQLite хранит проекты, адреса и их версии, рабочие группы и данные каталога, результаты проверок, расписания, уведомления и метаданные HTTP-профилей. Тела HTTP-ответов проверяемых адресов не сохраняются. Запросы к выбранным URL и удалённым sitemap идут по сети. Настроенный прокси получает проходящие через него запросы, а SMTP-сервер получает адрес получателя и сводку при отправке письма. Веб-интерфейс доступен на loopback-адресе текущего компьютера.

### Создание и восстановление копии

В Electron откройте **Настройки приложения → Экспорт базы** и выберите отдельный файл. Для восстановления нажмите **Восстановить базу**, укажите копию и подтвердите замену. Приложение проверит файл, сохранит прежнюю базу рядом под именем `pulse-before-import-….sqlite3` и перезапустится. Если копия логически некорректна, восстановление остановится с диагностикой. Незавершённые проверки из копии не продолжатся, а уже полученные результаты сохранятся. Включите **Выполнять расписания** в фоновых настройках, когда будете готовы возобновить плановые запуски.

Для копии веб-базы остановите сервер через `Ctrl+C`, дождитесь завершения и скопируйте файл базы в отдельное место. Для восстановления остановите сервер, сохраните копию текущей базы и положите выбранный файл по пути `URL_PULSE_DB` или `data/pulse.sqlite3`. При следующем запуске сервер обработает пропущенные запуски по расписанию. Для переноса между компьютерами настройте SMTP и секреты HTTP-профилей заново. Настройки SMTP и значения секретов хранятся отдельно от базы.

### Удаление данных

- Удаление URL из **Адресов** убирает его из активного списка. Результаты остаются в истории. Вернуть URL можно из карточки истории или повторным добавлением. Для очистки активного списка выберите **Все адреса**, сбросьте фильтры и нажмите **Действия → Удалить все адреса проекта**. Подтверждение показывает, какие проверки будут остановлены. Перед очисткой завершите или остановите перенос из каталога.
- В разделе **Каталог sitemap** можно удалить отдельный источник или сбросить фильтры и нажать **Очистить каталог**. Очистка удаляет источники, их версии и историю импорта, останавливает импорт и перенос. Уже перенесённые URL и отчёты остаются в проекте.
- Кнопка **Удалить отчёт** в открытом законченном прогоне удаляет результаты и связанное уведомление. **Настройки → Проект → Удалить проект** удаляет проект целиком вместе с адресами, прогонами, расписанием и уведомлениями после подтверждения. При активной проверке, отправке письма, импорте или переносе сначала завершите эту операцию.
- Чтобы удалить весь локальный профиль, сначала завершите приложение или сервер. Удалите каталог данных Electron либо базу веб-версии вместе с её служебными файлами и при необходимости `.env`. Отдельно проверьте сохранённые выгрузки, копии, созданные при восстановлении, и резервные копии, которые вы переносили в другие папки.

## Частые вопросы и ошибки

| Что произошло | Что проверить |
| --- | --- |
| В браузере нет сессии или приложение недоступно. | Убедитесь, что `npm start` работает. Откройте свежую полную ссылку из терминала в том же профиле браузера. Если сервер сообщает, что порт 8731 занят, завершите другой локальный процесс, который его использует. |
| База уже открыта. | Завершите другую копию через `Ctrl+C` или **Выход**. Повторите запуск. |
| В браузере сайт открывается, а проверка падает. | Проверьте HTTP-код, конечный URL и этап сбоя в отчёте. Сравните настройки HTTPS, заголовков и маршрута. Проверка выполняет самостоятельный GET и не использует сессию браузера. Частные и зарезервированные IP отклоняются. |
| Получен `401`, `403` или `407`. | Для `401` и `403` проверьте авторизацию сайта и назначение HTTP-профиля. Для `407` проверьте настройки авторизации прокси. Если сайт вернул признаки проверки Curator, они отображаются в диагностике результата. |
| В sitemap есть ошибки или кнопки для выбора URL неактивны. | Посмотрите итог быстрого импорта или статус задания в **Импорты**. Проверьте XML, доступность вложенных документов и границы импорта. В каталоге примените новые фильтры через **Найти** и дождитесь загрузки. |
| Расписание или письма не работают. | Проверьте, запущено ли приложение, часовой пояс и глобальную паузу Electron. Для писем проверьте **Когда уведомлять**, **Email получателя**, SMTP и состояние доставки в ленте. |

Диагностика URL доступна в отчёте. Ход импорта показан в разделе **Импорты**, а состояние отправки письма в разделе **Уведомления**. Веб-сервер пишет предупреждения и ошибки в терминал. Для Electron, запущенного через `npm run desktop`, проверьте вывод того же терминала и текст системного диалога, если приложение не запускается.

Если проблему нужно передать разработчикам, приложите версию приложения, ОС, способ запуска, язык интерфейса, шаги воспроизведения и текст ошибки. Удалите из примеров ключ входа, секреты профилей, email и приватные URL. Для уязвимости используйте канал из политики безопасности.
