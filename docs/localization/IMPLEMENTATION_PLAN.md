## Критерии приёмки

1. Все поверхности из реестра получили проверенную локализацию или обоснованное исключение для системного, технического, внешнего, пользовательского либо исторического текста.
2. Локализация обновляется без перезапуска и сохраняется. Проходят проверки состояния, автообновления, смены с открытой формой, окна и перезапуска.
3. Русский сценарий на данных 1.5.1 совместим. Оба языка проходят общую матрицу. Снимки отчётов, SMTP и настройки соблюдают заданную локаль. CSV/JSON совместимы.
4. Словари валидируются автоматически. Третий язык добавляется каталогом и регистрацией локали без изменения бизнес-логики. Отчёт различает число логических ключей, переводов и покрытие. Покрытие = проверенные локализованные элементы / все подтверждённые элементы согласованной области, исключения перечисляются отдельно.
5. Исходные тесты, сборки и визуальные прогоны подтверждены командами, числами и артефактами. Пропуски платформ и исторические исключения видны в отчёте.

## Откат

Пользователь может вернуть русский из интерфейса. Для выпуска сохраняются исходный тег и резервная копия из 1.5.1, изменения добавляются небольшими обратимыми коммитами. Перед релизом прогнать открытие копии новой базы версией 1.5.1 и восстановление старой копии новой версией. Если совместимость новой базы со старым приложением ограничена, откат проводить на копии с точно указанным несовместимым полем, сохраняя отдельно новые данные. Удаление колонок или перезапись пользовательских данных в автоматический откат не входит.
