# Глоссарий Пульса URL · URLPulse glossary

Терминология для интерфейса, писем, выгрузок Excel и руководств. Коды, идентификаторы и имена форматов в API сохраняются.

Use these terms in the interface, email, Excel exports, and documentation. Keep API codes, identifiers, and format names stable.

| Русский | English | Контекст · Context |
|---|---|---|
| Пульс URL | URLPulse | Название в интерфейсе · App name. The installer uses Pulse URL |
| Адреса | URLs | Вкладка рабочего списка · Worklist tab |
| Проверить проект | Check project | Запуск проверки · Start a run |
| Проверка | Check | Результат запроса или действие · Request outcome or action |
| Запуск, прогон | Run | Сущность с ID и результатами · A record with an ID and results |
| Журнал запусков | Run history | Список запусков · List of runs |
| Рабочая группа | Work group | Набор URL в проекте · A set of project URLs |
| Каталог sitemap | Sitemap catalog | Список URL из источников · URLs from sitemap sources |
| В рабочий список | Add to URLs | Перенос из каталога · Transfer from the catalog |
| Доступно, с ошибками | Available, Failed | Сводка и фильтры · Summary and filters |
| Не проверен | Not checked | URL без актуального результата · URL without a current result |
| Остановить проверку | Stop run | Сохраняет частичные результаты · Keeps partial results |
