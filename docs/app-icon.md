# Значок Пульса URL

- `desktop-assets/pulse-icon.png` — цветной PNG 1024 × 1024 для настольного приложения.
- `desktop-assets/pulse-icon.icns` и `desktop-assets/pulse-icon.ico` — ресурсы для сборки macOS и Windows. NSIS использует тот же ICO для установки и удаления.
- `public/pulse-icon.png` — PNG 128 × 128 для вкладки браузера и боковой панели.
- `desktop-assets/pulse-tray-template.png` и `desktop-assets/pulse-tray-template@2x.png` — монохромный значок строки меню macOS в размерах 18 × 18 и 36 × 36.

Исходный цветной значок и монохромная версия созданы во встроенном ImageGen с прозрачным фоном.

## Запрос для цветного значка

> Use case: logo-brand. Create one polished square desktop application icon for Pulse URL, a URL availability monitor. Single centered white connected signal glyph: a clean heartbeat zigzag made of one thick rounded line with subtle circular endpoint nodes, set on a rich indigo-to-violet rounded-square tile. The line reads at 16 pixels. Distinctive compact waveform, crisp graphic edges, minimal soft dimensional lighting within the tile, slight tonal depth. The tile should fill about 84% of the square with equal safe margins, true transparent space outside the rounded tile, no exterior shadow. Front-facing flat view, isolated, high contrast, editorial quality. No text, no letters, no frame, no stars, no secondary mark. Return a single icon on transparent background.

## Запрос для строки меню macOS

В качестве референса подан цветной значок.

> Create the monochrome status-bar version of the provided Pulse URL application icon. Preserve the geometry of the pulse waveform and its two round endpoints. Remove the purple tile entirely. Render only that waveform in pure opaque black on genuinely transparent background, with smooth antialiased edges. Center it horizontally and vertically, span about 84% of the square width, compact bold line for recognition at 16 × 16. No text, no border, no shading, no backdrop, no additional marks.
