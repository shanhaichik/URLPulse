## Проверка реализации

25 ноября 2026 года. Кандидат 1.6.0 на базе `78c6d33`. Node.js 24.22.3, macOS 26.5.2 arm64. Для проверок использованы временные базы, профили и синтетические URL.

Повреждённое значение даёт русскую локаль. При запрете чтения и записи `urlpulse.locale` приложение открылось по-русски и продолжило менять язык в текущей вкладке.

## Производительность

Размер основного JS вырос на 157,34 кБ после минификации и на 47,78 кБ gzip. Оба каталога входят в локальную сборку, поэтому переключатель доступен без внешней сети. React подписывается на смену языка в корне приложения. Компоненты получают локаль из контекста и используют готовые переводчики.

Холодное открытие списка адресов измерено в локальном Chrome на одном проекте с 10 000 синтетических URL, на одинаковом Fastify и машине. Браузерный `MutationObserver` фиксировал появление первой строки таблицы с начала навигации. Сборки чередовались. На каждую версию — 20 новых браузерных контекстов после прогрева. Смена языка измерялась от события выбора до двух кадров после изменения атрибута `lang`. Перцентили вычислены методом ближайшего ранга.

| Сценарий | p50 | p95 |
|---|---:|---:|
| Первый результат, интерфейс 1.5.1 | 70,7 мс | 72,8 мс |
| Первый результат, интерфейс 1.6.0 | 81,9 мс | 86,7 мс |
| Смена языка, 20 замеров RU ↔ EN | 32,6 мс | 33,2 мс |

Медиана холодного открытия выросла на 11,2 мс в локальном замере. Результат относится к этой машине и размеру проекта.

## Пересборка установщиков для проверки

25 ноября 2026 года собраны тестовые установщики версии 1.5.1 из текущих исходников `feature/i18n` на Node.js 24.22.3. Сборка и 22 целевых теста локализации прошли. Сверена SHA-256 всех трёх установщиков. В каждом пакете содержимое всех 72 файлов `dist/` совпадает с новой компиляцией.

- Apple Silicon DMG смонтирован, из образа запущены общий smoke-тест и тест локализации. Оба прошли.
- Intel DMG смонтирован. Тест локализации приложения из образа прошёл через Rosetta. Общий smoke-тест дважды завершился на загрузке простого PAC с ответом `400` и сообщением о превышении времени выполнения. Второй прогон шёл после завершения упаковки. Проверка PAC на нативном Intel остаётся открытой.
- Windows x64 собран через Forge и NSIS 3.13. Исполняемый файл приложения имеет архитектуру x86-64.

На Windows остаётся проверить выбор English/Russian, повторную установку, отказ при запущенном приложении и деинсталляцию. Пакеты собраны локально без подписей издателя.
