# Изменения Пульса URL

## 1.5.1

- Исправлен путь к файлам при упаковке установщика Windows x64.
- Стабилизированы тесты экспорта, импорта sitemap и ленты уведомлений.
- CI проверяет веб-сборку, тесты с покрытием и установщики для macOS Apple Silicon, macOS Intel и Windows x64. Перед публикацией исходников workflow проверяет соответствие версии тегу и успешный CI на коммите тега.

## 1.5.0

Первый релиз исходного кода под лицензией MIT. Веб-версия запускается локально с Node.js 24.x. Настольное приложение можно собрать для macOS Apple Silicon, macOS Intel и Windows x64. Команды описаны в [README](README.md).

- Списки адресов, рабочие группы, массовые действия и история версий URL по проектам.
- Каталог sitemap с фоновым импортом XML и XML.GZ, отслеживанием изменений и переносом в рабочий список. Поддерживаются каталоги до 1 млн уникальных URL на проект.
- Ручные и плановые прогоны, остановка с сохранением частичных результатов и запуск заново.
- Сравнение двух прогонов со статусами, кодами HTTP, временем ответа и диагностикой. Экспорт отчётов и сравнений в CSV, CSV для Excel и JSON.
- Настройки HTTPS, HTTP-заголовки, авторизация сайта, прокси и PAC по проектам. Российский корневой CA подключается отдельно по инструкции в README.
- Лента уведомлений, почтовая доставка по SMTP и резервное копирование SQLite в Electron.
- Защита локальной веб-сессии, проверка целостности базы перед восстановлением и восстановление состояния после аварийного завершения.
