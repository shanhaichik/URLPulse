# Аудит покрытия тестами Пульса URL

23 ноября 2026 года · Node.js 24.22.3 · macOS arm64 · SQLite и сетевые фикстуры на временных данных.

## Как измерено покрытие

- **Node.js и общие модули.** Vitest с V8 измеряет строки, ветви, функции и инструкции во всех файлах `src/server`, `src/desktop` и `src/shared` с расширением `.ts`. В отчёте остаются точки входа с нулевым покрытием. Исполнение в отдельных Worker и процессах Electron требует отдельных измерений. `preload.cts` проверяется через нативный smoke-тест.
- **React.** Playwright запускает временную сборку с Istanbul и картами исходников. Суммируются счётчики успешно пройденных сценариев, включая перезагрузки страницы. Браузерный набор проверяет веб-интерфейс. Сценарии с имитацией моста проверяют поведение React при ответах IPC. Нативное окно, сам мост и системные диалоги дополнительно проверяет Electron.
- **Пакеты.** Локально проверены Electron из исходников, настройки приложения и свежий неподписанный DMG arm64. В проверку DMG вошли контрольная сумма, монтирование только для чтения, ссылка на `/Applications`, архитектура и запуск упакованного приложения. Матрица GitHub Actions содержит Windows x64, macOS arm64 и macOS x64.

## Добавленные проверки по типу

- [x] **Позитивные.** Публикация каталога через API, массовый перенос и экспорт, восстановление очереди, сохранение настроек SMTP, повтор успешной операции после ошибки.
- [x] **Негативные.** Ошибочные фильтры, расписания, PAC и XML, операция над данными другого проекта, необратимый SMTP-отказ, повреждённая резервная копия.
- [x] **Пограничные.** Точный лимит в байтах, первая запись за лимитом, повторный час при переходе времени, обрыв выгрузки, параллельные SQLite-операции и выбор активной базы через ссылку.

## Воспроизведение

- `npm run test:coverage` — Node.js, отчёты в `coverage/node/`.
- `npm run test:coverage:browser` после `npx playwright install chromium` — React, отчёты в `coverage/browser/`.
- `npm run test:desktop` и `node e2e/desktop-settings-smoke.mjs` — нативные сценарии.
- `packaging/smoke-macos.sh` и `packaging/smoke-windows.ps1` — проверки готовых пакетов. В CI сборка использует чистый профиль и отдельный каталог вывода.
