# Исходное состояние Пульса URL перед локализацией

Проверено 25 ноября 2026 года. За основу взят `v1.5.1` (`78c6d33`). Дерево чистого рабочего коммита `b19092a` совпадало с деревом тега. Результаты запуска собраны в [TEST_REPORT.md](TEST_REPORT.md).

## Архитектура и границы изменения

- **React 19, TypeScript и Vite.** Один клиент обслуживает web и Electron. Маршрут хранится в параметрах URL и истории браузера. `app.tsx` хранит открытые диалоги, обратную связь операций и guards для черновиков. `api.ts` опрашивает данные по пути и ревизии. Переключение языка должно обновлять представление, сохраняя экземпляры компонентов и их данные.
- **Node.js 24 и Fastify.** В web локальный сервер обслуживает приложение и API, а в Electron main передаёт разрешённые IPC-запросы в Fastify. Контракт HTTP-ошибок обычно содержит `{ error }`, а IPC также использует отдельные технические `code`. Часть ответов и состояний хранит уже сформированный текст.
- **SQLite, workers и SMTP.** База содержит историю проверок, задачи каталога, настройки проектов и очередь писем. Результаты содержат машинные статусы наряду с сохранёнными ошибками. Фоновая доставка работает при закрытом интерфейсе, поэтому она нуждается в собственном источнике локали. Запросы к SMTP и сети остаются отдельными от локализации.
- **Electron 45 и Forge.** Main создаёт окно, глобальное меню, трей и файловые диалоги. Electron использует атомарную запись `desktop-preferences.json` и `safeStorage` для секретов SMTP. Windows NSIS жёстко задаёт Russian и проверяет русское название окна. Строки интерфейса можно менять независимо от имени exe, AppUserModelID, ключей реестра и протокола.
- **Состояние локализации.** Библиотеки i18n, общих каталогов и сохраняемого выбора в версии 1.5.1 нет. `index.html` задаёт `lang="ru"`, `ui.tsx` форматирует даты и числа в `ru-RU`. Использование русского locale в поиске и сортировке входит в наблюдаемое поведение, отдельное от выбора языка интерфейса.

## Реестр

[INVENTORY.tsv](INVENTORY.tsv) содержит **1 222 вхождения с кириллицей в 54 файлах**, из них 955 уникальных нормализованных текстов. Перечень построен по отслеживаемым файлам `src`, `packaging`, `public`, `desktop-assets`, `index.html`, `package.json` и `forge.config.cjs`. Для TypeScript/JavaScript разобраны JSX-тексты, строковые литералы, JSX-атрибуты и шаблонные выражения через Compiler API TypeScript. HTML, JSON, SVG и скрипты упаковки проверены построчно. Фрагменты выражений и повторное использование учитываются как вхождения. Эта метрика считает кандидатов, включая технические строки, и служит исходным реестром для классификации при переносе. ## Риски перед переносом

1. Ремонтопригодность теряется, если хранить готовый перевод в состоянии или БД. Хранить тип и аргументы, форматировать при выводе.
2. Изменение формата Excel может затронуть внешние таблицы. Локаль выбирать явно в новом вызове, сохранять прежний русский ответ для старого клиента.
3. При смене языка открытая форма может пересоздаться, а опрос — запуститься заново. Провайдер локали следует разместить выше `App` без `key` по языку. Операции должны продолжаться по прежним ID.
4. Трей, письмо и экспорт живут дольше рендера. Передавать неизменяемую локаль операции, избегать общей изменяемой локали на сервере.
5. Оболочка использует светлые панели и тёмную боковую панель. Переключателя темы в коде нет. Визуальная проверка охватывает доступные состояния, системные цвета нативных меню и оба варианта баннеров документации.
